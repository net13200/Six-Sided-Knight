# Design mockups

Exploration renders, not part of the game build. Each mockup uses the real game art and rules.

- `die.ts` / `die.html`: die readability ideas: (1) the die drawn as a cube seen from above, (2) the outcome of each move shown next to the die. Run `npm run dev` and open `/mockups/die.html`.
- `die-mockups.png`: close-up comparison (today, idea 1, idea 1 + 2).
- `die-phone-compare.png`: the whole board at phone size (today vs idea 1 + 2).
